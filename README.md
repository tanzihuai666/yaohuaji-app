# 妖画集 (Yaohuaji) · 离线纯净画师手账 App

> **定位**：离线可用、无广告、零网络请求的画师约稿与角色设子管理工具。  
> **画风基调**：粉彩贴纸卡通（Pastel Sticker Cartoon）——奶油底色、马卡龙调色、大圆角、柔和彩色投影、Q 弹微动效。

---

## 一、架构规范与数据结构 (v7)

- **本地原生存储**：通过 `@capacitor/filesystem` 读写原生 `DATA` 目录中的 `yaohuaji_data.json`。
- **浏览器预览双模**：若处于非原生环境，自动透明降级使用 `localStorage`，实现零报错离线体验。
- **数据结构字段**：
  - `version`: 7
  - `orders`: 约稿稿单列表（客户、类型、状态、价格、规格、用途、排期、提醒、备注、压缩画作列表）
  - `chars`: 自家设子档案（名字原地编辑、头像、基本身体数据、锚点背景故事、约稿记录折叠组与花费自动求和）
  - `types`: 约稿分类（支持新增自定义分类与长按删除）
  - `folders`: 无限嵌套文件夹树
  - `galleryImages`: 画库画作（支持统一 1600px/0.72 高质压缩、双层缩略图）
  - `priceList`: 稿条价目表海报配置（支持分级项目、3列示例图网格、离线 Canvas 长图导出到相册）
  - `settings`: 画师昵称、个性标语、头像、9套主题标识、自定义背景图与透明度

## 二、安卓原生插件清单 (AppToolsPlugin)

在 `android/app/src/main/java/com/yaohuaji/app/` 中实现：
1. **相机与相册权限** (`checkPermissions`)
2. **系统准点通知** (`setAlarmClock` + `NotificationReceiver`，免除精确闹钟权限繁琐适配，开机自恢复 `BootReceiver`，点击通知返回 App)
3. **退出 App** (`exitApp`，配合物理返回键双击防误退)
4. **保存到系统相册** (`saveToGallery`，适配 Android 10+ MediaStore 与低版本外部存储)
5. **分块流式拷贝至系统下载** (`streamCacheToDownloads`，64KB 流式写入防 OOM，杜绝 0 字节问题)
6. **SAF 存储访问框架保存与读取** (`safSave` / `safOpen`)
7. **系统文件夹选择器** (`pickFolder`)

### 权限声明 (`AndroidManifest.xml`)
- `INTERNET`
- `CAMERA`
- `POST_NOTIFICATIONS`
- `RECEIVE_BOOT_COMPLETED`
- `VIBRATE`
- `SCHEDULE_EXACT_ALARM`
- `USE_EXACT_ALARM`
- `WRITE_EXTERNAL_STORAGE`

## 三、4 大主导航与 17 个视图

1. **首页 (仪表盘 Dashboard)**：顶部日期、画师名片（头像/昵称/标语）、2×2 贴纸数据卡（总接单 / 钱包 / 已完成 / 稿条）、"手边的稿子" 快捷卡片流。
2. **稿单 (日历 + 列表联动)**：多 Token 搜索框、状态与类型筛选 Chip、排序下拉菜单、带接单绿点/截稿珊瑚点标记的月日历、稿单卡片状态推进。
3. **稿单详情页**：全字段展示、剩余天数徽章、状态推进、编辑、删除、查看/下载原图（隐藏底部导航）。
4. **新建/编辑稿单表单**：多选压缩画图、长按删除自定义分类、多字段联动、操作过程数据防丢。
5. **画库 (文件夹树与相册)**：无限嵌套面包屑导航、文件夹卡片、设子档案轮播、画作网格、批量管理与删除。
6. **新建文件夹模态框**
7. **角色档案页**：点击名字原地编辑、头像上传、基础属性标签、约稿记录折叠组与累计稿费自动累加。
8. **新建/编辑角色模态框**
9. **组内添加约稿模态框**
10. **批量导入约稿模态框**：多图批量选择，逐张配置稿价与备注。
11. **稿条 (海报式价目表)**：海报排版、01/02 编号、价格区间、3 列网格示例图、底部猫爪印章。
12. **稿条分享长图**：离线 Canvas 自动合成高分辨率竖长海报，一键存入系统相册。
13. **记账钱包**：累计总收入、当年收入、当月收入、全年 12 个月逐月明细柱状概览。
14. **我的 (个人主页)**：功能宫格导航与快捷入口。
15. **个人资料设置**：画师昵称、标语、头像修改。
16. **主题与背景切换**：9 套主题一键换肤（默认粉彩、黑粉夜色、山楂果茶煮、枫叶天妇罗、蓝藻奶巧、海盐气泡水、樱花奶冻卷、薄荷气泡水、纸间手账），自定义背景图与透明度滑块调节。
17. **存储与备份**：空间占用统计、分块打包 ZIP 导出至下载、导入 ZIP 不覆盖合并、清空数据确认。
- **附带**：全屏大图查看器（带索引计数与左右滑动切图）、离线纯净承诺弹窗。

## 四、本地运行与构建指南

### 1. 启动本地浏览器体验
```bash
python3 preview.py
# 浏览器将自动打开 http://localhost:8088
# 按 F12 打开移动端调试视窗（例如 iPhone 14 Pro 或 Pixel 7）即可体验极致手感
```

### 2. 同步 Web 代码至 Android 原生工程
```bash
npx cap sync android
```

### 3. 打开 Android Studio 构建 APK
```bash
npx cap open android
```
直接点击 Android Studio 中的 **Run** 或 **Build APK** 即可生成可在真实安卓手机上运行的 Release/Debug 安装包！
